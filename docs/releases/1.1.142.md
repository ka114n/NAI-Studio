# NAI Studio 1.1.142

本次更新改进手机输入体验和图片保存隐私，并同步调整双端入口名称。

## 更新内容

- 手机提示词输入跟随实际光标，修复编辑中间文字时画面总跳到末尾的问题。
- 双端「画师超市」更名为「所长法典」。
- 双端关闭「保存图片元数据」后，清理 PNG 文本、EXIF 及支持的 NovelAI alpha/RGB 像素隐写；清理失败时报告保存失败，不再原样输出。生成参数仍保留在应用内历史索引中。
- 手机关闭「保存到系统相册」后，自动生成、编辑、放大等输出仅保存到应用私有目录，不再自动另存到自定义共享文件夹。
- 手机新安装默认关闭系统相册保存；已有安装保留原先选择。
- 手机长按图片后，详情卡片底部显示可复制的应用内原图路径。
- Windows 包补齐完整及简化网页笔刷资源。

## 下载与升级

- `NAI-Studio-Windows-1.1.142.zip`：解压后运行 `NAI Studio.exe`，保留整个目录，无需另装 Java。
- `NAI-Studio-Android-1.1.142.apk`：Android 8.0 及以上，沿用 1.1.140 的正式签名，可覆盖同签名版本。
- `NAI-Studio-Source-1.1.142.zip`：本次发布的源码快照。
- `SHA256SUMS.txt`：上述三个文件的 SHA-256 校验值。

已有用户需在设置中关闭系统相册保存，才能启用私有保存行为。旧版已导出到相册或共享文件夹的图片不会自动删除。应用私有图片随应用卸载清除，卸载前请自行导出需要保留的内容。
