# NAI Studio 3.0

本次正式版本号为 **3.0.0**，供现有应用内更新器识别。从上一次公开版本 1.1.148 更新到当前双端开发版本。

## 更新内容

- 删除 Google 翻译选项及程序内本地转发服务；保留百度翻译、LLM 翻译和词典优先流程。原来选用 Google 的设置会迁移到已配置的百度翻译，没有百度配置时回到 LLM。
- 翻译或滑动调整权重时，数字结尾的 tag 会在闭合 `::` 前增加空格，避免生图模型将 tag 尾数误读为权重。
- 新主词库共 330,745 条，首次打开词典或点击翻译时由用户选择是否下载，之后复用本机缓存。支持模糊搜索、多个中文对应同一英文 tag、增补、修改及确认删除词条；普通翻译仍精确匹配。
- 新增提示词中英对照卡片，支持就地编辑、滑动调整权重、拖动排序与垃圾桶删除，风格提示词同步支持。
- 优化角色分区：独立角色搜索候选可直接创建并展开卡片，正负提示词各有工具栏，翻译采用精确匹配。手机候选列表限高并在抽屉内滚动，改善键盘遮挡和输入框挤压。
- 优化无限画布的自动遮罩扩图、回贴、保存及图像预览，完善手机相册导出。
- 电脑端增加本地 PixAI Tagger 反推、电脑配对 HTTPS 共享及 RTX 2× 放大功能，相关配对设置收纳到设置页；所需模型与运行环境按需下载。
- 电脑端工具改为可收纳右侧栏，完善 Windows 原生文件选择和图片拖入目标识别，改善大图片导入、缩放预览与“我的”页布局。

## 安装与升级

- Windows：下载完整 ZIP，解压后运行 `NAI Studio.exe`，保留 `app` 与 `runtime`。已有更新器的正式版本可从应用内检查更新，使用完整包更新。
- Android：使用原正式签名，可覆盖同签名版本并保留应用数据。历史测试签名（例如原 1.1.139）仍需先导出完整备份再迁移，请勿在备份未确认成功时卸载旧应用。
- 词库约 38 MB 独立下载，不内置于安装包。电脑本地反推及 RTX 组件首次使用需下载额外模型和运行环境；电脑配对共享需要电脑运行且网络可达。
- 翻译设置中的百度/LLM 凭据由用户自行提供。Google 翻译已移除。

## 下载

- `NAI-Studio-Windows-3.0.0.zip`：包含 Java 运行环境的 Windows 完整便携版。
- `NAI-Studio-Android-3.0.0.apk`：Android 8.0 及以上，正式签名。
- `NAI-Studio-Source-3.0.0.zip`：本次发布的 NAI Studio 源码快照。
- `SHA256SUMS.txt`：附件 SHA-256 校验值。
