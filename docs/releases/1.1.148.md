# NAI Studio 1.1.148

优化双端第三方 NAI API 使用，并新增 Android 完整迁移备份。

## 更新内容

- 双端移除第三方图生图和遮罩重绘的固定拦截，由 NAI Gate／上游服务器按权限决定是否允许；服务器拒绝时保留具体错误原因。
- 选择第三方接口后，凭据输入改为「第三方 API Key」，验证和清除提示同步调整。
- Key 下方显示服务器提供的 V5 今日剩余和本月 Anlas 剩余，支持手动刷新。没有额度数据时显示提示，不显示假 0，也不把网关模拟的官方订阅当成真实订阅。
- 修复 Windows 第三方地址输入与请求地址不一致的问题；切换站点或 Key 时清除旧额度，避免旧响应覆盖当前数据。
- Android 新增密码加密的完整迁移备份与恢复，包含已保存图片、设置及 API Key 等凭据；导出后回读校验。备份文件含机密信息，请与密码分别保管。详见 [完整迁移说明](https://github.com/ka114n/NAI-Studio/blob/v1.1.148/docs/FULL_MIGRATION_BACKUP.md)。

## 安装与升级

- Windows：ZIP 已包含运行环境，解压后运行 `NAI Studio.exe`。已有更新器的版本可在应用内检查更新。
- Android：沿用正式签名，可覆盖同签名版本，保留应用数据。旧测试签名（包括原 1.1.139）不能直接覆盖，请先完整备份迁移；本次公开附件不包含旧测试签名导出版。不要在尚未确认备份成功时卸载旧应用。
- 第三方剩余额度需服务器提供兼容接口；显示的 Key 额度仍受服务器其他共享限额约束。
