# NAI Studio 1.1.143

双端新增应用内更新，后续升级可以直接在应用中完成。

## 更新内容

- 启动后在后台检查最新正式版本，发现更新时显示版本及更新说明；设置 → 关于中也可点击「检查更新」。
- 下载显示进度，并校验文件大小及 SHA-256；检查失败不会阻塞应用启动。
- Windows：确认更新后自动下载、暂存新程序，退出后替换程序文件并重启。设置、凭据、历史与图片保留；替换失败时恢复旧文件。
- Android：在应用内下载 APK，校验包名、签名与构建版本后交给系统覆盖安装。首次需要授权本应用安装其他应用，授权后再点「安装更新」。
- 修正 Windows 应用内版本显示，确保更新判断与实际安装版本一致。

## 首次升级

**1.1.142 及更早版本没有更新器，需要手动升级到本版一次。**

- Windows：退出旧程序，解压本版 ZIP 后运行 `NAI Studio.exe`，保留整个目录。用户数据位于独立的数据目录，不需要删除。
- Android：直接安装本版 APK，可覆盖同正式签名版本；不要卸载旧版，以保留应用内数据。不同签名的旧测试版不能直接覆盖。

安装本版后，未来版本可以从应用内更新。当前使用完整安装包自动下载，不是差分补丁；应用关闭时不会收到系统推送。

## 下载

- `NAI-Studio-Android-1.1.143.apk`：Android 8.0 及以上，沿用正式签名。
- `NAI-Studio-Source-1.1.143.zip`：本次源码快照。
