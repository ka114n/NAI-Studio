# 应用内更新

从 1.1.143 起，双端启动约 8 秒后在后台检查公开仓库的最新正式 Release；设置 → 关于中也可手动检查。应用关闭时不会接收系统推送。网络检查失败不会阻塞启动，手动检查会显示错误。

发现新版本后显示更新说明，由用户确认下载和安装。下载显示进度，校验 Release 的 SHA-256 与文件大小。当前使用完整安装包自动下载，不是差分补丁；无需手动删除旧目录或卸载应用。

## Windows

仅已打包的 Windows 应用支持自动安装，开发环境不会覆盖源码。更新包暂存在 `%APPDATA%/NAI Studio/updates`，解压检查目录越界、重复路径、允许的文件路径与体积上限。安装助手隐藏启动并等待原进程退出，只替换 `app`、`runtime`、`NAI Studio.exe`、`NAI Studio.ico`。

程序目录需要当前用户可写。已有设置、凭据、历史和图片所在的数据目录不参与替换；程序目录旁的其他文件也保留。原程序文件暂存于本次更新目录的 `previous`，替换失败时回滚并重启原程序。结果与错误记录在该目录的 `result.txt` / `helper.log`，用于恢复和排查。

## Android

APK 下载到应用私有缓存，不写入系统相册。安装前检查包名、签名及更高的 versionCode；使用只开放更新缓存目录的 FileProvider 将 APK 交给系统安装器。首次需要允许本应用安装其他应用，授权后再点「安装更新」。覆盖安装由系统确认，保留用户数据；不要卸载旧版。不同签名的旧测试版不能通过此更新器覆盖。

## 发布约定

更新源为 `https://api.github.com/repos/ka114n/NAI-Studio/releases/latest`，忽略草稿和预发布版。正式版本使用三段数字版本号及 `v` 前缀标签，附件必须名为 `NAI-Studio-Windows-X.Y.Z.zip` / `NAI-Studio-Android-X.Y.Z.apk`，同时具备 GitHub 计算的 SHA-256 digest。Windows ZIP 根目录直接包含应用文件，与 1.1.142 的发布包一致。

1.1.142 及更早版本没有更新入口，首次需手动切换到含更新器的版本。以后直接从应用内更新。源码备份不会自动发布 Release。

## 1.1.143 验证

Windows 538 项测试（6 项跳过），Android 494 项测试，均无失败。新增覆盖版本比较、稳定版筛选、下载地址与校验值拒绝、损坏/截断文件、解压越界，以及实际 Windows PowerShell 文件替换和故障回滚事务。事务测试用临时目录并模拟程序重启，不修改用户安装。

GitHub 实际版本检查、APK 下载与 SHA-256 校验通过；Windows 打包启动、APK 正式签名及版本检查通过。没有连接的 Android 实体设备，系统授权和覆盖安装交互仍需真机验证。
