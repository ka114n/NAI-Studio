# Android 完整迁移备份

本地 1.1.146 提供两种签名的同一程序：旧测试签名导出版用于覆盖原 1.1.139；正式签名版用于迁移后的恢复。两种签名不能互相直接覆盖安装。本次仅作本地交付，未发布公开 Release。

## 先导出，不先卸载

1. 安装 `NAI-Studio-Android-1.1.146-legacy-full-backup.apk` 覆盖旧测试签名应用。不要卸载原应用，也不要清除数据。
2. 在「我的 → 完整迁移备份（含密钥和图片）」点击「导出完整备份」，设置并确认至少 8 位的备份密码。
3. 保存 `.naibackup` 到「下载」等应用目录外的位置。等待「回读校验通过」。失败时保留原应用，排查空间、文件权限、缺失原图等问题后重试。
4. 将备份文件和密码分别妥善保管。备份包含 API Key 与机密信息，不能公开上传或提交 Git。

只有确认完整导出及回读校验成功后，才考虑签名迁移：卸载旧签名应用，安装本地正式签名 `NAI-Studio-Android-1.1.146.apk`，在同一入口选择「恢复完整备份」，输入密码，等待恢复完成，点击「关闭应用」后重开。共享输出文件夹需要重新授权；服务器仍可能使原登录令牌失效。

## 范围与限制

- 包括全部已保存 SharedPreferences 设置、未知扩展键、API Key、登录凭据、图库索引/分组、应用私有文件、历史原图、放大图、无限画布快照及原点记录、预设文件、对话记忆，以及设置或索引中引用且可读取的外部文件。
- 不包含未保存编辑、内存撤销栈、其他应用的数据、Android Keystore 私钥、系统授权状态，也不等同于整台手机备份。
- 关闭参数持久化时保留原有休眠参数记录；不会为了导出用当前默认参数覆盖它们。
- 导出前等待已有写入完成。导出文件回读解密并校验清单、文件大小与 SHA-256；缺失历史原图或当前无限画布必需文件会中止导出。
- PBKDF2-HMAC-SHA256 派生密钥，AES-256-GCM 分帧加密。密码不会写入设置。密码遗忘无法恢复。
- 导入先验证全部加密数据和清单再替换当前保存数据。密钥在目标安装的 Keystore 下重新加密；普通失败回滚，进程中断由下次启动的私有恢复日志处理。
- 新入口独立于原设置 JSON / 图片内嵌备份，原功能保留。历史 JSON 备份不包含本次完整迁移数据。

## 构建与验证

从 `phone/naistudio` 使用 JDK 17、配置好的 Android SDK 运行：

```powershell
.\gradlew.bat :app:testLocalDebugUnitTest :app:assembleLocalRelease --no-daemon
```

签名配置和密钥从项目外的独立签名备份读取，不加入 Git。APK 为本地验证文件，不纳入源码仓库。桌面端未修改。

验证结果记录于 `BACKUP.md`。没有连接实体 Android 手机，覆盖安装、SAF 文件选择和真机完整迁移仍需用户验证。
